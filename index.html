One-time setup (Apps Script)

1. Open your spreadsheet → Extensions → Apps Script.
2. Delete any placeholder code and paste in the script shown below the tool (written out separately).
3. Click Deploy → New deployment, choose type Web app.
4. Set "Execute as" to Me, and "Who has access" to Anyone.
5. Click Deploy, authorize it, then copy the /exec URL it gives you into the field above.
A sheet tab called Trips will be created automatically the first time you send data, with a Lane and Route column already computed so you can sort/filter it directly in Sheets.
